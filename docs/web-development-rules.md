# web-development-rules.md — Web開発の共通ルール(段階別・制約)

> CLAUDE.md から移管。実装・公開・収益化の各段階で**必ず参照**する。
> 記事の書き方ルールは各サイトの `docs/article-style-guide.md`(self)を参照。

## スタック
- **Next.js + Vercel/Cloudflare + 独自ドメイン**。
- 記事は**SSG**、中核ツールは**CSR + noindex**(完成HTML配信 → 無料・商用OKのホスティングに載る)。

## ガードレール(守るべき制約)
- **E-E-A-T は本人の専門性(人事・組織・経営)で担保**する。テーマは専門領域から選ぶ。
- Google の「スケール化されたコンテンツの濫用」を避ける:
  - 記事は量産しない(**1サイト 10〜20本の質重視**)。
  - 一度に大量公開せず、人間のペースで。
  - テンプレ流用の薄いページを作らない。
- 診断・計算等の**結果はインデックスさせず動的表示**(薄いテンプレ=doorway ページを作らない)。
- 収益は **広告(AdSense)+ 結果画面・記事内の関連アフィリエイト** の2軸。有料商品は当面作らない。
- サイトの第一印象を「売り込み(LP)」にしない。**情報を整理して読者が自分で判断できる**ことを前面に(無料・登録不要・個人情報の入力なし・出典明記)。

## 段階別ルール(確認 → 公開 → 収益化)
| 段階 | やること | 注意 |
|---|---|---|
| **開発・確認** | ローカル(localhost)/プレビューで作る。全ページ `noindex` | 公開前に検索エンジンへ載せない |
| **公開(A-3)** | `noindex` を外す。独自ドメイン接続・HTTPS。**商用OKのホスティング**へ | Vercel Hobby は非商用 → AdSenseを載せるなら **Cloudflare Pages(無料・商用OK)** 等へ |
| **収益化** | 必須3ページ用意 → AdSense審査・申請 → 広告設置 → 計上 | 中核ツールの結果ページは noindex のまま |

## ホスティングの商用利用
- **Vercel Hobby(無料)= 非商用向け**。AdSense(広告)を載せると商用扱い → 規約に注意。
- **Cloudflare Pages(無料)= 商用OK**。SSG中心の本サイトと相性が良い。ドメイン購入・DNSも同社で完結でき最安・最簡。
- 開発・確認は Vercel 無料枠で可。**AdSense本番は商用OKの無料枠へ移す**。

## 技術SEO(公開前チェックリスト)
- メタ:各ページ `title`(KW前方・40〜60字目安)/ `description`(150〜160字)。`title.template` で統一。
- 構造化データ(JSON-LD):**Article/BlogPosting → BreadcrumbList → Organization+Person(著者)**。FAQ/HowToのリッチリザルトは終了済み(実装不要)。可視内容と一致必須・順位要因ではない。
- `sitemap.xml` / `robots.txt`。
- `canonical` / OGP。
- Core Web Vitals:LCP<2.5s / CLS<0.1 / INP<200ms(画像に width/height・lazy、主要画像は遅延しない)。
- アクセシビリティ:H1は1ページ1つ・見出し階層・リンクテキスト自明・コントラスト4.5:1。

## AdSense 要件(収益化の前提)
- **独自ドメイン必須**。
- **記事10本以上**(質重視)。
- **プライバシーポリシー / 問い合わせ / 運営者情報** の3ページを用意。
- 本人確認・住所・口座/税情報の登録(本人作業)。
